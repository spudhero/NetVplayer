## 视觉语言

1. 纯白主背景与浅灰分区交替，让每一屏只表达一个产品重点。
2. 标题采用高对比深灰，说明文字保持克制宽度与清晰行距。
3. 海蓝只用于主要下载动作、文本链接和必要的焦点反馈。
4. 产品截图使用完整画面与轻量边框，不叠加装饰性光效或拟物框架。
5. 动效仅使用低位移淡入，禁用弹跳、缩放炫技与连续视差。
6. 下载按钮和兼容信息以 GitHub 最新正式 Release 为真源；静态 HTML 保留当前正式版本回退，脚本只采用严格匹配版本化 arm64 ZIP 名称的资产。
7. 项目背景使用编辑式双栏叙事，不展示其它项目图标或截图，也不暗示官方移植关系。
8. 安装步骤使用连续编号行，FAQ 使用原生折叠项；两者都保持页面区块感，不嵌套装饰性卡片。
9. 扩展支持使用应用内真实运行截图，高级诊断保持收起；配套文字明确首次准备和后续更新需要能访问 GitHub，且不展示源信息、凭据或本机路径。
10. README 与官网只展示当前产品信息；具体版本修复记录统一链接到仓库根目录的 `CHANGELOG.md`。
11. 产品介绍按内容接入、浏览播放、音画字幕、使用步骤与架构组织；新增区块复用现有编号行、双栏图文、留白和浅灰分区，不使用版本更新卡片。
12. 当前产品截图使用真实安装版；源地址、来源昵称等直接在图片像素中遮挡，海报与影视名称强降采样后模糊，移除原图元数据。网页不得依靠 CSS 模糊保护原图。播放器可展示明确标注的自制本地演示视频。
13. 截图入口不代表真实账号或硬件验收成功。翻译标明 macOS 15+，HDR／音频标明实际输出条件，Mac／Android 选择说明重启生效和独立执行。图文指南与架构图使用同一套产品术语。

整体方向：以 Apple 产品页式留白和层级呈现一款原生、可信、由用户掌控内容的 macOS 播放器。
