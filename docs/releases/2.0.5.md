# NetVplayer 2.0.5

正式构建：**56**，适用于 **macOS 14+／Apple Silicon**。

- 修复播放诊断每秒重复枚举系统 HDR 显示器，导致普通视频和杜比视频画面周期性停顿的问题（#15）。稳定请求复用状态，显示器变化时重新检查，HDR 切换期间仍确认结果；屏幕名称与显示模式按窗口事件刷新。
- 修复百度分享目录请求遗漏已授权账号的问题，并隔离当前分享会话。服务返回 9019 时明确提示先完成百度官方验证、再重新扫码授权；停止自动重复请求，保留已有文件映射（#16）。真实账号或服务风控仍需在百度侧完成验证。
- 保留 2.0.4 的 Android 异步媒体交接修复。Mac 与 Android 原版继续严格二选一，Android 完整环境 1.2.4，Mac 原生扩展 1.1.14。

替换应用保留配置、账号、历史和收藏；切换实现后重启。旧版本及验收证据保留。服务端空响应、媒体 CDN 拒绝和缺少原生实现的来源不计为播放通过。代表样本不等于全部来源、真实账号和所有硬件均通过。

## English

Build **56**, for **macOS 14+ / Apple Silicon**.

Fixes periodic picture stalls caused by playback diagnostics repeatedly enumerating system HDR displays (#15). Stable requests reuse state; display changes and pending HDR transitions still refresh. Screen names and modes refresh on window events.

Baidu share listing now includes the selected account while isolating each share session. Error 9019 stops automatic retries, preserves saved-file mappings, and directs users to official account verification followed by QR authorization in Settings (#16). Account-specific verification remains subject to Baidu.

Includes the 2.0.4 asynchronous Android media-handoff fix. Mac and original Android remain exclusive, using native extension 1.1.14 or the complete Android runtime 1.2.4. Previous releases and scoped acceptance evidence remain intact.
