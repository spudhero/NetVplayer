# NetVplayer 2.0.7

正式构建：**58**，适用于 **macOS 14+／Apple Silicon**。

- 修复网盘原画自动切换转码后，画面已播放但加载提示一直不消失的问题。
- 修复 Android 原版切换来源后误用另一来源的本机媒体端口，导致网盘影片播放失败的问题；失效服务按原有一次重试预算重建。
- 修复部分 HDR Vivid 影片暗部斜率解包错误造成的亮度反相；保留既有 PQ／HLG 动态映射方式。
- 修复部分来源的目录条目被当成影片详情，支持逐层进入目录并选择实际资源。
- 配套 Mac 原生 Python 扩展 **1.1.19**、Java 扩展 **1.1.4**，修复 AI 剧签名、厂长媒体提取、部分分类／搜索／直播列表与备用域处理，并补齐爱刷、粤迷、橘猫的原生实现。使用 Mac 实现时在设置中检查扩展更新。

Android 完整环境保持 **1.2.4**。两种实现继续独立，切换后重启。替换应用保留配置、账号、历史和收藏。

代表样本已检查实际解码或应用画面，不能据此保证所有影片。部分来源仍受上游 TLS、验证页面、媒体 CDN 拒绝或无可用资源影响；目录和海报加载成功不计为播放通过。此前另一个 H.264 转码偏色样本仍未定位，不属于本次 HDR Vivid 修复范围。

## English

Build **58**, for **macOS 14+ / Apple Silicon**.

- Clears the loading overlay when a cloud fallback stream is already advancing beyond the original seek target.
- Prevents original Android providers from using another helper's local media port after switching sources, with the existing single retry for a failed service.
- Corrects HDR Vivid shadow-slope bit decoding that could reverse luminance in dark areas.
- Opens source directory entries as folders before selecting playable resources.
- Ships alongside native Python extension **1.1.19** and Java extension **1.1.4**, with catalog, request-signing, media-extraction and backup-domain fixes, plus three additional native adapters. Check extension updates in Settings when using the Mac implementation.

The complete Android runtime remains **1.2.4**. Mac and Android implementations remain independent; restart after switching. Replacing the app preserves configuration, accounts, history and favorites.

Representative samples were checked for actual decoding or app frames. Upstream TLS failures, verification pages, rejected media and unavailable resources remain scoped limitations. Artwork or catalog loading alone does not establish playback. A separately observed H.264 transcode color issue remains unresolved.
