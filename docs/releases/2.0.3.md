# NetVplayer 2.0.3

正式构建：**54**，适用于 **macOS 14+／Apple Silicon**。

- 修复网页解析已收到视频响应，仍交给网页插件而导致播放失败的问题；支持原地址及无扩展名媒体接管，保留原始站点检查和请求头边界。
- Android 原版采用完整运行组件 **1.2.4**，修复宿主与 JavaScript 引擎不匹配及部分旧脚本缺少通用 HTML 接口的问题。
- 首次启用 Android 时自动更新不兼容的旧组件。匹配的已安装组件继续离线复用；Mac 模式不检查或下载 Android，两个实现保持严格二选一。

替换应用即可，无需清除配置、账号、历史或收藏。切换实现需要重启。通用桥接／构建实现、固定上游对应源码及许可证见 [Android 组件 1.2.4](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/android-original-runtime-v1.2.4-arm64)。来源 JAR 仍由用户配置提供。

2.0.2 及旧组件保留历史原物。来源服务、账号授权及上游接口可能影响个别站点；回归与代表来源实测不代表全部来源、真实账号、NAS、macOS 14 实机或长期播放均通过。

## English

Build **54**, for **macOS 14+ / Apple Silicon**.

Fixes playback failing when web parsing receives a media response but WebKit tries to use its media plug-in. Confirmed original and extensionless media URLs now transfer to the player, retaining the original source check and request-header boundaries.

Original Android uses the complete signed **1.2.4** runtime, matching the host with its embedded JavaScript engine and adding the optional generic HTML API needed by legacy scripts. Incompatible older installations update before their first Android session; matching installations reopen offline. Mac mode never prepares Android, and implementation selection remains exclusive.

Replace the application without clearing user data. Restart after switching implementations. Generic bridge/build sources, fixed upstream corresponding sources and notices accompany the [runtime release](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/android-original-runtime-v1.2.4-arm64). User-configured source JARs remain separate. Existing service, account, hardware and sustained-playback validation limits remain applicable.
