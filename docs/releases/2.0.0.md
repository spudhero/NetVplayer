# NetVplayer 2.0.0 — unreleased / 尚未发布

当前主程序开发构建：**49**。稳定下载仍为 **1.1.4 (build 18)**。
本页描述开发分支已有实现及验证限制，不代表 2.0 已正式发行。

## 中文

- 新增 Android 原版组件执行与路径选择。组件独立下载和验证，用户自行提供内容配置；主程序不附带来源目录、账号或媒体。Android 与原生账号分别保存，Android 来源之间可复用支持的网盘授权。
- 新增个人网盘目录、Plex、FTP／SFTP、极影视／飞牛影视接入，并完善 WebDAV、Alist／OpenList、SMB 与本机文件的浏览和海报媒体库。
- 改进播放器事件处理、海报按需加载、后台任务预算、分页搜索、设置搜索、节目单时间解析、在线元数据和直播预览缓存。
- 调整窄窗口、长列表和长消息布局。修复搜索栏拉伸、UC 目录选择卡死，以及首页取消后辅助进程争用状态目录的问题。
- 网盘授权显示完整说明，用户扫码操作有独立等待预算；对话框仅显示当前最上层，正文可换行和滚动。
- 修复可明确识别的百度旧转存记录；UC 登录后的空播放结果沿用一次有界恢复。阿里自动原片首次启动使用 60 秒宽限。
- 修复部分 AI 内容的本机媒体服务端口失配和 MP4 编码标记。构建 49 已在两轮换源操作中观察到画面与进度恢复；这不代表所有来源或全部新设备均已通过。
- 弹幕状态与重试放在弹幕面板，来源接口地址使用通用名称；默认关闭和已有开关偏好保留。

### 已知限制

- 阿里／夸克等原片持续缓冲仍有未解决样本；启动成功不代表持续播放通过。
- 部分来源仍返回空弹幕；界面修复不代表来源内容已恢复。部分磁力链接仍有文件信息等待超时。
- 新安装、真实网盘、不同 NAS、全部来源的完整验收尚未完成。原生 AI 扩展的设备注册恢复与应用版本独立验证，不能把本机成功扩展为所有设备通过。
- macOS 14 实机、长时间播放、物理输入、特定音视频硬件与性能认证仍保留各自待验范围。
- 开源源码门禁、应用包校验、真实服务实播分别提供证据；任何一项通过都不能替代整体验收。

## English

Development application build **49** is unreleased. The stable download remains **1.1.4 (18)**.

This branch adds original Android component execution and backend selection, personal cloud
folders, Plex, FTP/SFTP and NAS integrations. It improves poster scheduling, playback events,
bounded search, settings search, programme guides, metadata and live previews. It also fixes
specific directory/UI stalls, authorization waits and helper lifecycle failures.

The public application contains no bundled content configuration, source catalog, account or
media. The app-owned dialog renderer is published with its Java source and a pinned archive;
external components remain independently verified.

Sustained original-stream buffering, empty danmaku from some services, some magnet timeouts,
fresh-device compatibility, complete real-account acceptance, macOS 14 hardware tests and
long-playback/performance checks remain open. Build 49 recovered picture and progress in two
local source-switching checks; that evidence does not establish universal service support.

See [Contributing](../../CONTRIBUTING.md) and the [presentation source guide](../../android-presentation/README.md)
for source validation. Source audits, packaged-app checks and real playback acceptance are separate.
