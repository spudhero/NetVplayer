# NetVplayer 2.0.4

正式构建：**55**，适用于 **macOS 14+／Apple Silicon**。

- 修复 Android 原版已收到视频响应，等待原版来源检查时被 WebKit 页面取消通知提前中断的问题。原版来源检查拒绝、用户取消及超时仍生效。
- Mac 实现与 Android 原版继续严格二选一。Android 使用完整签名运行环境 **1.2.4**；兼容的已安装环境继续离线复用，Mac 不准备 Android 环境。

替换应用即可保留配置、账号、历史与收藏，切换实现需要重启。通用桥接与构建源码、固定上游对应源码及声明见 [Android 完整组件 1.2.4](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/android-original-runtime-v1.2.4-arm64)。来源 JAR 仍由用户配置提供。

2.0.3 及此前发布物、标签和失败记录保留。个别来源的服务或账号状态、缺少原生实现的站点、真实账号、NAS、macOS 14 实机及长期播放，仍须分别验证；代表样本通过不代表全部来源均可播放。

## English

Build **55**, for **macOS 14+ / Apple Silicon**.

Fixes confirmed media handoff failing while the original Android Spider check is still pending: WebKit's deliberate policy cancellation no longer ends parsing early. Source rejection, user cancellation and timeouts remain effective.

Mac and original Android remain exclusive. Android uses the complete signed **1.2.4** runtime; compatible installations reopen offline. Mac never prepares Android. Replace the application while keeping user data, and restart after changing implementations. Generic bridge/build sources and upstream corresponding sources accompany the [runtime release](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/android-original-runtime-v1.2.4-arm64).

Previous releases and failure evidence remain intact. Per-source services, accounts, unsupported native sources, hardware and sustained playback retain separate validation scopes.
