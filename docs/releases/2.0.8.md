# NetVplayer 2.0.8

构建 **59**，适用于 **macOS 14+／Apple Silicon**。

- 点播的字幕、音轨、比例、倍速、章节和音量面板沿用底栏的半透明样式。恢复竖向音量控制，音量面板打开时也能用滚轮调节。静音或零音量显示带斜线的喇叭。
- 恢复章节列表和进度条的章节缩略图，改善部分网盘原画的取帧速度。点选章节仍跳到章节起点。
- 修复部分点播 HLS 在跳转后无法起播的问题。磁力播放命中缓存种子时会保留磁力链接原有的 Tracker。
- 改善 Android 原版来源的扫码窗口切换和辅助进程回收。部分起播请求返回 HTTP 500 时，应用会重建对应辅助进程后重试一次。
- 配套 Mac 原生 Java 扩展 **1.1.6** 改善韩迷、花生和有声小说配置的目录与播放。可在「设置 → 扩展支持」检查更新。Android 完整环境版本为 **1.2.4**。

可以在应用内检查更新，也可以下载安装包并替换「应用程序」中的 NetVplayer。替换应用保留现有配置、账号、历史和收藏。

## English

Build **59** for **macOS 14+ / Apple Silicon**.

- Subtitle, audio track, aspect ratio, playback speed, chapter, and volume popovers use the same translucent appearance as the player controls. The vertical volume slider is back, and scrolling adjusts volume while its popover is open. Mute and zero volume show a crossed-out speaker.
- Restores chapter thumbnails in the chapter list and on the timeline. Preview frames load faster for some original-quality cloud streams. Selecting a chapter still seeks to its start.
- Fixes startup for some redirected on-demand HLS streams. Magnet playback retains the original trackers when cached torrent metadata is available.
- Improves sign-in window activation and helper cleanup for original Android sources. When certain playback requests return HTTP 500, the app recreates the corresponding helper and retries once.
- Companion native Java extension **1.1.6** improves browsing and playback for Hanquan, Huashu, and audiobook configurations. Check for updates in Settings → Verified Extensions. The complete Android runtime version is **1.2.4**.

Use the in-app updater or download the ZIP and replace NetVplayer in Applications. Your configuration, accounts, history, and favorites are kept when you replace the app.
