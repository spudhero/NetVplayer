# NetVplayer 2.0.1

发布日期：**2026-11-16**。正式构建：**52**，适用于 **macOS 14+／Apple Silicon**。

建议 2.0.0 用户升级本版。直接替换应用即可，无需删除配置、账号、历史或收藏。

- 修复安装后初始化崩溃、随后反复出现恢复启动页的问题。Android 对话框主题改用应用内资源；重新安装旧的 2.0.0 包不能修复此问题。
- 修复正常退出时异步清理可能卡住的问题。保留保存播放进度、停止组件、清理失败重试与重启交接；清理完成后再退出。
- 发布前增加实际安装包启动与退出检查：解压最终归档、移开构建目录资源，要求应用完成真实初始化、生成验收画面并正常结束；失败或超时会阻止发布。

本版通过完整源码回归、三个原生 AppKit 退出场景、解压 App 启动／退出、arm64、签名、源码边界、运行库最低系统版本、更新签名和附件一致性检查。视觉检查使用隔离夹具，不代表真实媒体播放验收。

应用仍使用社区 ad-hoc 签名，首次打开方式见 [安装说明](https://github.com/spudhero/NetVplayer#安装)。Python Provider 1.1.13、Android 支持包 1.1.0 沿用既有版本。

阿里／夸克等原片持续缓冲、部分来源空弹幕、真实账号与 NAS、全部来源、macOS 14 实机和长期播放等既有待验范围继续保留，见 [2.0.0 功能与限制](https://github.com/spudhero/NetVplayer/blob/main/docs/releases/2.0.0.md)。[#14](https://github.com/spudhero/NetVplayer/issues/14) 保留打开，等待报告者升级后的实际反馈。

## English

Released **2026-11-16**, application build **52**, for **macOS 14+ / Apple Silicon**.

Users of 2.0.0 should upgrade. Replace the app without deleting settings, accounts, history or favorites.

Fixes an installed-app initialization crash caused by resolving the Android dialog theme from a SwiftPM build resource path. The app now uses its packaged resources. Reinstalling the old 2.0.0 archive does not fix this crash.

Also fixes asynchronous cleanup being blocked during normal termination. Playback progress, component shutdown, cleanup retry and restart handoff remain coordinated before exit.

Validation includes the full source regression, three native AppKit termination scenarios, extracted-app startup and normal exit while build resources are hidden, architecture, signing, source boundaries, runtime deployment targets, signed updates and byte-for-byte release assets. The visual fixture does not establish real-media playback acceptance. Existing real-account, source, hardware, macOS 14 device and sustained-playback limitations remain open. Community ad-hoc signing and existing Provider versions continue to apply.
