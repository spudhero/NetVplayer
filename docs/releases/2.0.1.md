# NetVplayer 2.0.1

状态：发布准备中。候选构建 **52**，尚未正式发布。

修复 2.0.0 安装后初始化时可能直接崩溃、随后显示恢复启动页的问题。Android 对话框
主题初始化现在使用正式 App 内的资源包定位方式，不再直接依赖 SwiftPM 构建目录。
此问题发生在业务初始化阶段，暂缓恢复上次状态也可能触发；重新安装同一旧包不会修复。

同时修复正常退出等待异步清理时可能卡住的问题。退出请求先暂缓，让清理任务完成后
重新退出；保留进度保存、组件停止、失败重试及重启交接。

发布验证增加解压后的 App 实际启动检查，并临时移开构建目录的同名资源包，确保验证
不依赖开发缓存。通过现有隔离视觉模式初始化并生成画面后才允许打包流程继续。
正式发布前仍需完成源码回归、真实打包启动、签名、兼容性、更新签名和附件核对。

此补丁不代表全部来源、真实网盘账号、macOS 14 实机或长期播放验收完成。

## English

Release preparation: candidate build **52**, not yet published.

Fixes an initialization crash in installed 2.0.0 applications caused by resolving the Android
dialog presentation archive through a SwiftPM build resource path. The app now uses its
packaged resource bundle. Release validation starts the extracted app while the build resource
fallback is hidden, and requires a rendered capture before continuing. Full release checks
remain required; existing source, device and sustained-playback limitations still apply.

Also fixes asynchronous cleanup being blocked by the AppKit termination modal loop. The app
finishes cleanup before requesting termination again, preserving retry and restart handoff.
