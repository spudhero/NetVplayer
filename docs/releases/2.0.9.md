# NetVplayer 2.0.9

构建 **60**，适用于 **macOS 14+／Apple Silicon**。

- 支持在原生播放器里直接解码 ByteVC2 MP4，免去整段视频转码。
- 部分 HTTP 点播提前中断时，应用会尝试从当前集的播放位置恢复一次。Android 原版会在确认媒体服务归属后为启动预留时间，并在该服务中断时重启对应辅助进程。
- Android 原版会跳过文件名能明确辨识为同一剧集系列中其他季或其他集的外挂字幕，减少无效字幕请求。

可以在应用内检查更新，也可以下载安装包并替换「应用程序」中的 NetVplayer。替换应用保留现有配置、账号、历史和收藏。

## English

Build **60** for **macOS 14+ / Apple Silicon**.

- Play ByteVC2 MP4 files directly in the native player without transcoding the full video.
- The app can retry some interrupted HTTP on-demand streams once at the current position. Original Android sources get time for their verified media service to start, and the app restarts the corresponding helper if that service is interrupted.
- Original Android sources skip external subtitle files whose names clearly identify a different season or episode of the same series.

Use the in-app updater or download the ZIP and replace NetVplayer in Applications. Your configuration, accounts, history, and favorites are kept when you replace the app.
