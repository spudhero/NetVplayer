# NetVplayer 2.0.9

构建 **60**，适用于 **macOS 14+／Apple Silicon**。

- 支持在原生播放器里直接解码 ByteVC2 MP4，免去整段视频转码。
- 部分 HTTP 点播提前中断时，应用会尝试从当前集的播放位置恢复一次。Android 原版会在确认媒体服务归属后为启动预留时间，并在该服务中断时重启对应辅助进程。
- Android 原版会跳过文件名能明确辨识为同一剧集系列中其他季或其他集的外挂字幕，减少无效字幕请求。

配套组件已独立发布。Mac 实现的 Python 目录扩展 **1.1.23** 恢复 AI 短剧原生取流。Android 原版完整环境 **1.2.5** 升级至 FongMi 5.9.0 和 QuickJS 1.1.2。 [Python 1.1.23](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/provider-netvplayer.catalog.python-v1.1.23-arm64) · [Android 1.2.5](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/android-original-runtime-v1.2.5-arm64)

Python 扩展可在「设置 → 扩展支持」中检查更新。已有 Android 1.2.4 的用户可下载并解压 1.2.5，在 Android 原版运行组件处选择解压后的组件文件夹，安装后重启。

可以在应用内检查更新，也可以下载安装包并替换「应用程序」中的 NetVplayer。替换应用保留现有配置、账号、历史和收藏。

## English

Build **60** for **macOS 14+ / Apple Silicon**.

- Play ByteVC2 MP4 files directly in the native player without transcoding the full video.
- The app can retry some interrupted HTTP on-demand streams once at the current position. Original Android sources get time for their verified media service to start, and the app restarts the corresponding helper if that service is interrupted.
- Original Android sources skip external subtitle files whose names clearly identify a different season or episode of the same series.

The companion Python catalog **1.1.23** restores native media retrieval for AI short dramas in Mac mode. The complete Android runtime **1.2.5** includes FongMi 5.9.0 and QuickJS 1.1.2. [Python 1.1.23](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/provider-netvplayer.catalog.python-v1.1.23-arm64) · [Android 1.2.5](https://github.com/spudhero/NetVplayer-Provider-Distribution/releases/tag/android-original-runtime-v1.2.5-arm64)

Check for Python updates in Settings → Verified Extensions. To upgrade from Android 1.2.4, download and extract 1.2.5, select that folder in the Android Original Runtime settings, and restart NetVplayer.

Use the in-app updater or download the ZIP and replace NetVplayer in Applications. Your configuration, accounts, history, and favorites are kept when you replace the app.
