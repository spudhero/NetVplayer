# 标题

NetVplayer更新了

# 正文

我一直在做的原生 Mac 播放器 NetVplayer，正式更新到 2.0.8 了。这篇聊聊从 1.1.4 到现在的重大变化，配上首页、NAS 详情和播放器实拍，最后附上安装教程👇

🧩 TVBox／FongMi 兼容性更强了
支持兼容的配置。对比 1.1.4，新增 Android 原版执行方式，在独立环境中运行配置引用的原始 JAR；也可选 Mac 原生适配。两种方式切换后重启，界面与媒体播放仍为原生 Mac。兼容性取决于具体配置及服务。

🗂️ 自己的媒体库，接入更多了
新增 Emby、Jellyfin、Plex、极影视、飞牛影视接入，以及个人网盘文件夹和 FTP／SFTP。已有的 NAS 海报墙、详情、文件版本和续播继续保留，这次也补上详情页实拍。

🎬 杜比音画，更完整了
杜比视界支持 P5／P8 动态映射、P7 FEL 双层重建；兼容链路可用 DD+ JOC／TrueHD Atmos 直通。播放信息区分素材格式与实际输出，效果取决于素材、设备及设置。

💬 字幕，也多了实用工具
新增 Apple 本机文本翻译、双语显示与导出，需 macOS 15+ 及语言资源。还有设置搜索、本机文件拖入、小窗与主题选择。

📦 小白从这里开始
需要 M 系列 Mac、macOS 14+。在 GitHub 搜索 NetVplayer，认准 spudhero → Releases → 2.0.8 → Assets，下载 NetVplayer-2.0.8-macos-arm64.zip。双击解压，把 App 拖进“应用程序”再打开。
社区构建未公证；首次被系统阻止时，确认下载可信后，按“系统设置→隐私与安全性→仍要打开”处理。

▶️ 安装以后怎么用？
本机视频：菜单“文件→打开文件…”或拖入；若出现“待打开的文件”，展开选择它。
自己的配置：设置→内容来源→在线内容→影视配置链接→加载影视。想用 Android 原版，在“扩展支持→来源解析方式”选择并重启，首次准备需联网。
自己的 NAS：内容来源→NAS / 本地→添加连接→测试→选择文件夹建库。
