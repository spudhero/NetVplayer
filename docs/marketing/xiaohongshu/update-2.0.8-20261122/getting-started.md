# 新手安装与首次使用（2.0.8）

本说明从零开始，不依赖旧帖子。NetVplayer 是 Mac 播放器和个人媒体管理工具，应用不附带影视内容、服务器或账号。先用自己拍摄的视频完成一次本地播放，再按需连接自己的 NAS。

## 1. 确认电脑能用

点击屏幕左上角苹果菜单 →“关于本机”，检查：

- 芯片为 Apple Silicon，即 M 系列；当前安装包不适用于 Intel Mac。
- 系统为 macOS 14 或更新版本；Apple 本机字幕翻译另需 macOS 15+ 及受支持的语言资源。

## 2. 下载主应用

在 GitHub 搜索 **NetVplayer**，认准作者 **spudhero** 的项目。

1. 打开项目页面，找到 **Releases（发行版）**。
2. 进入 **2.0.8**，展开 **Assets（附件）**。
3. 下载 **NetVplayer-2.0.8-macos-arm64.zip**。

不要选择 `Source code (zip)`／`Source code (tar.gz)`：它们是源码，不是能直接打开的应用。组件仓库中的扩展包也不是主应用。
本说明固定对应 2.0.8；以后升级可在项目 Releases 中核对正式版本。

## 3. 解压并安装

1. 打开 Finder 的“下载”，双击下载好的 ZIP。
2. 找到解压得到的 `NetVplayer.app`，拖到 Finder 左侧的“应用程序”。
3. 从“应用程序”或启动台打开 NetVplayer。
4. 若系统阻止首次打开，先确认下载来自上述作者的项目正式发行页、文件未被改动。社区构建采用 ad-hoc 签名，未进行 Apple 公证；确认可信后，按 Apple 的打开 App 说明，到“系统设置 → 隐私与安全性”，找到对应提示，选择“仍要打开”，再按系统要求确认。不要全局关闭系统安全保护。

老用户先正常退出旧应用，再用新 App 替换“应用程序”里的版本。原有配置、账号状态、历史与收藏会保留；无需删除用户数据。

## 4. 先播放一个自己的本机视频

1. 准备自己拍摄并已传到 Mac 的视频，例如 MP4。
2. 打开 NetVplayer，在屏幕顶端菜单栏选择“文件 → 打开文件…”，选中视频；也可以将视频拖入应用窗口。
3. **如果右上角出现“待打开的文件”，展开该菜单，点击文件名开始播放。** 在已有页面打开文件时可能需要这一步。
4. 播放后，底部可暂停、调整进度、选择字幕／音轨、调整比例和倍速、进入小窗或全屏。没有内嵌字幕的视频不会凭空产生字幕。

单个本机视频无需先建媒体库或登录云端账号。首次组件准备及后续组件更新需要能访问 GitHub；正常情况自动完成，失败时到“设置 → 扩展支持”选择“重新检查”。已安装且校验有效的组件可离线使用，内容服务本身可能仍需联网。

## 5. 已有自己的 NAS，再添加媒体库

没有 NAS 可跳过本节。NAS 需已开机、启用相应文件服务，并能被这台 Mac 访问；家庭网络与远程访问方式由自己的 NAS 配置决定。

1. 打开“设置 → 内容来源 → NAS / 本地”（页面标题为“NAS 与本地媒体”）。
2. 点击“添加连接”，选择自己的实际连接方式，如 SMB、WebDAV、AList／OpenList、FTP／FTPS、SFTP 或本地目录。
3. 填写易认的名称、服务地址及对应账号信息；参数以自己的 NAS／服务端设置为准。
4. 点击“测试连接”。通过后点击“连接并选择文件夹”，选择一个或多个有权访问的视频目录，再选择合适的媒体库类型完成创建。
5. 回到首页，从来源菜单选择刚建立的媒体库。点击海报进入详情，查看资料与文件版本，再选择实际文件播放。

简介、评分、海报和演职员属于媒体资料，并不提供视频。NAS 详情和多文件夹功能在 1.1.4 已存在；本次宣传图补齐其 2.0.8 的实际外观。

已有 Emby、Jellyfin、Plex、极影视或飞牛影视服务器的用户，可在“设置 → 内容来源 → 在线内容”向下找到“媒体服务器”，选择类型并填写自己已有服务器的信息，然后“验证并连接”。

## 6. 使用自己的 TVBox／FongMi 兼容配置

此功能使用你已有且有权使用的配置。本说明不提供配置订阅地址、来源 JAR 或影视内容；具体兼容性取决于配置和服务。NetVplayer 为独立项目，与 TVBox／FongMi 无官方隶属关系。

1. 默认可先用 Mac 实现。若要使用新增的 Android 原版方式，到“设置 → 扩展支持 → 来源解析方式”，在“下次启动使用”选择“Android 原版”，然后按提示重启。查看“本次启动”和“实际解析方式”，确认选择已生效。
2. Android 原版首次加载配置时会自动下载、校验和激活完整签名环境，需要能访问 GitHub。失败时在“扩展支持”重新检查；Mac 模式不准备 Android 环境，两种方式不会自动互相回退。
3. 到“设置 → 内容来源 → 在线内容”（页面标题为“在线视频与直播”），把自己的兼容配置填入“影视配置链接”，点击“加载影视”。
4. 返回点播首页，从左上来源菜单选择已配置的来源；浏览分类或搜索，进入详情后选择线路和剧集开始播放。
5. 若来源要求自己的网盘授权，按对应提示完成。Android 来源内的授权与 Mac 原生网盘账号分别保存，不能用一边已登录推断另一边也已授权。

如有自己的直播列表，可在同页“直播频道列表”加载受支持的 JSON／M3U／TXT。应用不会提供频道内容，列表可读也不代表每个频道均可播放。

## 7. 常见情况

| 看到的情况 | 下一步 |
| --- | --- |
| 首页空白 | 正常。先打开一个自己的本机视频，或添加已有的 NAS／服务器／个人网盘目录。 |
| ZIP 解压后没有可直接打开的 App | 检查是否错下了 Source code 或扩展组件包。 |
| 首次组件准备失败 | 核对网络是否可访问 GitHub，到“设置 → 扩展支持”重新检查。 |
| NAS 测试不通过 | 核对服务已启用、地址／端口／账号正确，以及 Mac 对目标网络和目录有访问权限。 |
| 能浏览目录但无法播放 | 浏览成功不等于该文件可播；继续核对文件权限、格式及服务端状态。 |
| 没有杜比输出或翻译 | 分别检查素材、硬件链路及系统／语言条件，不能仅凭设置开关判断实际输出。 |

详细功能与条件见项目内 docs/guide.md 使用指南。本说明不包含影视资源获取、来源订阅或版权规避操作。
