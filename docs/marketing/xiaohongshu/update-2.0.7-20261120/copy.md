# 标题

我写的Mac播放器，2.0.7来了

# 正文

之前分享过我一直在做的原生 Mac 播放器 NetVplayer。这次更新到已经正式发布的 2.0.7，把自己的网盘、NAS、媒体服务器和本机文件，放进同一套浏览与播放体验里👇

🗂️ 内容散在不同地方，也能一起管理
支持夸克、UC、阿里云盘、百度、115 个人目录；NAS 可通过 SMB、WebDAV、AList／OpenList、FTP／SFTP 接入，也能连接 Emby、Jellyfin、Plex、极影视和飞牛影视。多选文件夹加入媒体库，用海报墙整理电影和剧集。

🎬 杜比视界，按设备调整画面
支持 Dolby Vision P5／P8 动态映射、P7 FEL 双层重建，按显示设备选择 HDR 输出或 SDR 映射。画面怎么输出，可以在播放信息里查看。

🎧 杜比全景声，也有对应的输出方式
连接兼容的功放或回音壁，可用 DD+ JOC／TrueHD Atmos 直通；日常观看也能调整音轨、音频设备和对白清晰度。实际效果取决于片源与设备链路。

💬 字幕，想多做一点实用的小工具
支持主副字幕、Apple 本机文本翻译，以及译文／双语字幕导出。翻译需要 macOS 15+，并提前准备语言资源；图片字幕和音频识别也有各自的使用条件。

🛠️ 2.0.7，重点继续打磨播放细节
修复部分网盘自动切换转码后加载提示不消失、Android 原版切换来源后的部分播放失败，以及部分 HDR Vivid 影片暗部亮度异常。目录条目也能逐层打开，再选择资源。

🔎 常用操作，尽量顺手
设置支持搜索，本机文件可以拖入播放；倍速、音轨切换、小窗置顶、历史续播和主题切换都放进了这套 Mac 界面。来源解析可选 Mac 实现或 Android 原版，更改后重启生效。

目前支持 Apple Silicon，macOS 14+。应用不附带视频源、直播列表或账号，请添加自己有权访问的内容；网盘和在线服务的可用性取决于账号权限与服务状态。

如果你也在 Mac 上整理自己的媒体库，最想先用哪一项？
