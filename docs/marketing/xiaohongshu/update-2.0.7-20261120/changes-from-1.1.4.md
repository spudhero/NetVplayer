# 1.1.4 → 2.0.7：值得讲的重大变化

以 **1.1.4（build 18）** 为旧版基线，对比 **2.0.7（build 58）**。按使用场景归纳，不逐条罗列补丁版本，也不把已有功能写成新增。安装和操作入口见[新手说明](getting-started.md)。

## TVBox／FongMi 相关：新增 Android 原版执行方式

TVBox、FongMi/TV 等 Android 生态的配置使用习惯，是 NetVplayer 的项目背景之一。配置兼容并非 2.0.7 才开始；这次重大变化是新增 **Android 原版** 执行方式：在独立兼容环境中运行用户配置引用的原始 JAR，目录、详情和播放解析使用同一路径。

用户也可以选择 **Mac 实现**，使用原生适配或签名扩展，不准备 Android 环境。两种方式在“设置 → 扩展支持 → 来源解析方式”选择，下次重启生效，不自动互相回退。无论哪种方式，应用界面和实际媒体播放均为原生 macOS。来源、账号与媒体由用户提供，兼容性不能扩大为全部 TVBox／FongMi 配置均可运行。

项目内依据：2.0.0 发行说明、当前解析方式说明。项目独立开发，与 TVBox／FongMi 没有官方隶属或合作关系。

## 媒体库：从已有 NAS，扩展到更多自己的内容

新增 Emby、Jellyfin、Plex、极影视、飞牛影视接入，增加个人网盘文件夹和 FTP／SFTP 文件服务，继续完善 WebDAV、AList／OpenList、SMB 和本机文件浏览。个人网盘支持夸克、UC、阿里云盘、百度和 115，可选多个文件夹加入媒体库。

**NAS 详情、多文件夹、文件版本与实际文件续播在 1.1.4 已有。** 本轮补拍当前详情页，是补充展示，而非宣称这次首次加入。

项目内依据：1.1.4 的功能与使用说明、1.1.4 发行记录、2.0.0 接入扩展、当前媒体能力。

## 音画：杜比视界、Atmos 和真实输出状态

1.1.4 后继续完善色彩与音频路线：Dolby Vision P5／P8 动态映射、P7 FEL 双层重建，以及兼容链路上的 DD+ JOC／TrueHD Atmos 直通；提供 HDR／SDR 输出策略、设备选择与更清楚的实际输出信息。播放信息区分素材格式与当前输出，不能仅凭文件标签判断输出效果。

视界动态映射不等于电视必然收到 Dolby Vision 信号；Atmos 直通需要兼容素材、设备与链路，原速且关闭音频处理。当前播放器宣传实拍是自制 SDR／PCM 本机视频，不作为杜比硬件验收。

项目内依据：当前杜比能力与条件、音画使用指南。

## 字幕和日常操作：翻译、导出、搜索与拖放

新增 Apple 本机文本字幕翻译，支持跟随播放或处理整份字幕、双语显示及译文／双语导出；图片字幕识别也有对应入口。Apple 本机翻译需 macOS 15+ 与受支持语言资源，不能把它当成 macOS 14 的默认能力。

日常操作增加设置搜索和本机视频拖入，继续整理音画参数、小窗和主题体验。已有字幕、音轨、倍速、历史与收藏保持；不把这些旧功能全部算作新增。

项目内依据：当前音画与字幕、使用指南。

## 当前版本的范围

2.0.7 是此次推荐使用的正式版本；其间的启动、退出、播放交接、周期卡顿、HDR／音频恢复等修复，不在宣传图里逐版展开。重大功能的当前状态以以上说明和对应使用条件为准。代表样本修复不等于全部文件、账号、服务或硬件均已验证；另一个 H.264 转码偏色问题不在本次修复承诺内。
